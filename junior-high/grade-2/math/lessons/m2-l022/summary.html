第22時限「A＝B＝Cの形の連立方程式と計算の基本演習」

この時間の目標

A＝B＝Cの形の連立方程式の解き方を理解し、これまでの連立方程式の計算を基本演習で確実に定着させることが目標です。

大事なポイント

  • A＝B＝C の形の方程式は、{ A＝B、B＝C } や { A＝C、B＝C } のように2つの方程式の組に書き直して解きます。
  • 3つの式のうち、一番簡単な式（定数だけなど）を両方に使うと計算が楽になります。
  • 加減法・代入法・かっこ・小数・分数・A＝B＝Cのすべての型を見分けられるようにします。

例題

方程式 2x＋y＝x−2y＝5 を解きましょう。

考え方：右端が定数5なので、{ 2x＋y＝5 …①、x−2y＝5 …② } に分けます。①×2＋②より 5x＝15、x＝3。①に代入して 6＋y＝5 より y＝−1 です。

答え：x＝3、y＝−1

つまずきやすいところ

  • A＝B＝C から式を2つ作るとき、3つのうち1つだけ使わない式がないように、A・B・Cすべてを少なくとも1回は使います。
  • 解が出たら、もとのA・B・Cすべてに代入して同じ値になるか確かめましょう。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
