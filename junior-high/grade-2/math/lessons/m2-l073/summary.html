第73時限「平行四辺形になるための条件（2組の対辺）の証明」

この時間の目標

ロボットのアームなどの仕組みの考察を通して、「2組の対辺がそれぞれ等しい四角形は平行四辺形である」ことを証明できるようになることが目標です。

大事なポイント

  • ある四角形が平行四辺形であることを証明するには、定義である「2組の対辺がそれぞれ平行（AB // DC かつ AD // BC）」を導けばよいことになります。
  • AB＝DC、AD＝BC の四角形ABCDに対角線ACをひくと、3組の辺がそれぞれ等しいので △ABC≡△CDA となります。
  • 合同から錯角 ∠BAC＝∠DCA、∠BCA＝∠DAC がそれぞれ等しくなるため、AB // DC かつ AD // BC となり、平行四辺形であることが証明できます。

例題

四角形ABCDで AB＝DC、AD＝BC のとき、AB // DC を導くための根拠となる角の関係を答えましょう。

考え方：対角線ACをひいて △ABC≡△CDA を示すと、対応する角が等しいので ∠BAC＝∠DCA となります。これは錯角が等しいことなので AB // DC がいえます。

答え：錯角 ∠BAC＝∠DCA が等しいから AB // DC

つまずきやすいところ

  • 平行を示すときは「錯角が等しいから」または「同位角が等しいから」という平行線になる条件を必ず明記しましょう。
  • 「平行だから錯角が等しい」と「錯角が等しいから平行」の向きを間違えないようにしましょう。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
