第71時限「平行四辺形の性質の証明」

この時間の目標

平行四辺形の3つの性質（対辺・対角・対角線）を、定義（2組の対辺が平行）と三角形の合同を用いて証明できるようになることが目標です。

大事なポイント

  • 対角線ACを1本ひくと、AB // DC、AD // BC の錯角が等しく、ACが共通なので「1組の辺とその両端の角」より △ABC≡△CDA が証明できます。
  • この合同から「AB＝CD、BC＝DA（2組の対辺が等しい）」と「∠B＝∠D（対角が等しい）」が導けます（∠A＝∠Cも錯角の和または別の対角線で示せます）。
  • さらに対角線ACとBDの交点をOとすると、△AOB≡△COD（AB＝CDと平行線の錯角2組）より AO＝CO、BO＝DO（対角線はそれぞれの中点で交わる）が証明できます。

例題

平行四辺形ABCDで対角線ACをひいたとき、△ABC≡△CDA を証明するための3つの等しい要素を挙げましょう。

考え方：平行四辺形の定義より AB // DC なので錯角 ∠BAC＝∠DCA、AD // BC なので錯角 ∠BCA＝∠DAC、さらに共通な辺より AC＝CA です。

答え：∠BAC＝∠DCA、∠BCA＝∠DAC、AC＝CA（1組の辺とその両端の角がそれぞれ等しい）

つまずきやすいところ

  • 性質を証明するときは、まだ証明していない性質（AB＝CDなど）を根拠に使わず、定義（平行）から出発する点に注意しましょう。
  • 対角線の性質を証明するときは、すでに証明した「対辺が等しい（AB＝CD）」を使って構いません。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
