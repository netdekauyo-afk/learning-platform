第84時限「助動詞を含む受け身（can / should＋be＋過去分詞）のしくみ」

この時間の目標

助動詞を含む受け身（can / will / must / should ＋be＋過去分詞）の形と意味を理解し、世界遺産が抱える問題についての文章を読み取れるようになることが目標です。

大事なポイント

  • 助動詞（can, will, must, should など）と受け身を組み合わせるときは、助動詞の後ろが原形になるため「助動詞＋be＋過去分詞」の形になります。
  • 例：World Heritage sites must be protected.（世界遺産は守られなければなりません）／ This problem should be solved.（この問題は解決されるべきです）／ It can be seen from here.（それはここから見ることができます）。

例題

「これらの古い建物はわたしたちによって守られなければなりません。」を must と受け身を使って英語で表しましょう。

考え方：These old buildings に続けて must be protected by us と並べます。

答え：These old buildings must be protected by us.

つまずきやすいところ

  • must is protected や must are protected とせず、助動詞の後ろは主語が単数でも複数でも必ず原形の「be」にします。
  • 否定文は助動詞の後ろに not（cannot be seen / must not be damaged）を入れます。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
