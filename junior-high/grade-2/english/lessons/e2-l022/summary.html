第22時限「接続詞（when・if・because・that）のまとめと復習演習」

この時間の目標

4つの接続詞（when・if・because・that）の意味・語順・コンマと時制のルールを総復習し、正確に使い分けられるようになることが目標です。

大事なポイント

  • when（～するとき）、if（もし～ならば）、because（なぜなら～だから）、that（～ということ）。
  • when / if / because が文頭にくるときは節の後ろにコンマ（,）を置きます。
  • when / if の節の中では、未来のことであっても現在形を使います。

例題

次の(　)に when、if、because、that のうち最も適切なものを入れましょう。(1) I know (　) he is a good singer.　(2) We won't go out (　) it rains tomorrow.

考え方：(1) 「～ということを知っている」なので that。(2) 「もしあした雨が降ったら」の条件なので if を入れます。

答え：(1) that　(2) if

つまずきやすいところ

  • 接続詞の後ろには必ず「主語＋動詞」の文が続くことを意識して並び替え問題に取り組みましょう。
  • 文脈から「時・条件・理由・内容」のどれをつないでいるかを見極めるのがポイントです。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
