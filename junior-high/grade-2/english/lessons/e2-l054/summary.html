第54時限「主語＋be動詞＋形容詞＋that節のしくみと読解」

この時間の目標

「主語＋be動詞＋形容詞＋that節（I'm glad that ～ / I'm sure that ～）」の形と意味を理解し、ユニバーサルデザインについてのスピーチを読み取れるようになることが目標です。

大事なポイント

  • glad / happy（うれしい）、sorry（残念だ）、surprised（驚いた）、sure（確信している）などの形容詞の後ろに「that＋主語＋動詞」を置くと、気持ちの原因や確信の内容を詳しく表せます。
  • 例：I'm glad that everyone can use this easily.（だれもがこれを簡単に使えてうれしいです）。
  • この that も会話などではよく省略されます。

例題

「わたしは、このデザインが多くの人々の役に立つと確信しています。」を I'm sure that ～ を使って英語で表しましょう。

考え方：I'm sure that の後ろに this design will help many people（または is useful for many people）を続けます。

答え：I'm sure that this design will help many people.

つまずきやすいところ

  • 同じ「うれしい」でも、後ろが「to＋原形」なら I'm glad to see you.、「主語＋動詞」の文なら I'm glad that you came. と使い分けます。
  • I'm sorry that ～ は「～して申し訳ない／～なのは残念だ」の両方で使われます。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
