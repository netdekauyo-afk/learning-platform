第81時限「受け身（受動態）の疑問文と世界遺産についての対話」

この時間の目標

受け身（受動態）の疑問文（Is / Are / Was / Were ＋主語＋過去分詞 ～?）と答え方を理解し、世界遺産などについて質問し合えるようになることが目標です。

大事なポイント

  • 受け身の文には be動詞が使われているため、疑問文は be動詞を主語の前に出すだけで作れます（例：Is Japanese spoken here? / Was this castle built in 1600?）。
  • 答え方は Yes, it is (was). / No, it isn't (wasn't). のように be動詞で答えます。
  • 疑問詞と組み合わせるときは When was it built?（それはいつ建てられましたか）や Where is it located? のように使います。

例題

「この城はいつ建てられましたか。― それは1609年に建てられました。」を英語で表しましょう。

考え方：When に続けて was this castle built? と聞き、It was built in 1609. と答えます。

答え：When was this castle built? — It was built in 1609.

つまずきやすいところ

  • Did this castle built? のように Did を使わず、必ず be動詞（Was / Were）を前に出しましょう。
  • 年号の前には前置詞 in（in 1609）を付けます。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
