第80時限「受け身（受動態：be動詞＋過去分詞）の肯定文・否定文」

この時間の目標

「～される」を表す受け身（受動態：be動詞＋過去分詞）の肯定文・否定文の形と意味を理解し、世界遺産などについての事実を説明できるようになることが目標です。

大事なポイント

  • 主語が「～される」という立場を表す形を「受け身（受動態）」といい、「主語＋be動詞（現在 am/are/is、過去 was/were）＋過去分詞」で作ります。
  • 規則動詞の過去分詞は過去形と同じ -ed（used, visited）、不規則動詞は3番目の形（make-made-made、speak-spoke-spoken、build-built-built、write-wrote-written、see-saw-seen）を使います。
  • 否定文は be動詞の後ろに not を置きます（例：English is spoken in many countries. / This temple was built in 1397.）。

例題

次の日本文を受け身の英語にしましょう。(1) 英語は世界中で話されています。(2) このお寺は昔建てられました。

考え方：(1) speak の過去分詞 spoken を使い English is spoken all over the world.。(2) 過去のことなので was と build の過去分詞 built を使い This temple was built long ago. です。

答え：(1) English is spoken all over the world.　(2) This temple was built long ago.

つまずきやすいところ

  • be動詞を忘れて English spoken ～ としたり、過去分詞ではなく原形・過去形（was wrote など）を使ったりするミスに気をつけましょう。
  • 不規則動詞の「原形–過去形–過去分詞」の3点セットを声に出して暗記するのが攻略のカギです。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
