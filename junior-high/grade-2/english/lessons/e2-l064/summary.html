第64時限「不規則変化の比較表現（better / best）のしくみと読解」

この時間の目標

不規則変化する比較表現（good / well → better → best、many / much → more → most）のしくみを理解し、調査結果の発表を読み取れるようになることが目標です。

大事なポイント

  • 不規則に変化する重要語：good / well（よい・上手に）→ better（よりよい）→ best（いちばんよい）、many / much（多くの）→ more → most、bad → worse → worst。
  • 「AよりBの方が好き」は like B better than A、「いちばん好き」は like ～ (the) best を使います。
  • 例：I like summer better than winter. / Which sport do you like the best?

例題

「わたしはすべての教科の中で英語がいちばん好きです。」を英語で表しましょう。

考え方：like English the best に「すべての中で」of all subjects を続けます。

答え：I like English the best of all subjects.

つまずきやすいところ

  • good の比較級を gooder、最上級を goodest にしないよう、better / best を確実に覚えましょう。
  • 「～より好き」は like A more than B よりも like A better than B が中学英語の定番です。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
