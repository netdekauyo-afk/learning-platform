第19時限「ご当地グルメ紹介（Unit Activity）の情報整理と記事作成」

この時間の目標

ALTの先生におすすめするご当地グルメ（Unit Activity）について、接続詞（when / if / because / that）を活用して紹介記事を作成することが目標です。

大事なポイント

  • 紹介記事の構成例：①おすすめ料理の紹介（I think that ～ is great.）、②味や特徴、③おすすめの理由（because ～）、④食べ方の提案（If you come to Kyoto, please try it!）。
  • 接続詞を使うことで、単調な短文の羅列から論理的で読みやすい文章へレベルアップできます。

例題

「もし京都に来たら、ぜひ八つ橋を食べてみてください。とても甘いので、きっと気に入ると思います。」を英語で表しましょう。

考え方：If you come to Kyoto, please try Yatsuhashi. に続けて I think you will like it because it is very sweet. とつなげます。

答え：If you come to Kyoto, please try Yatsuhashi. I think you will like it because it is very sweet.

つまずきやすいところ

  • If の中では現在形（come）、主節の予想では will（will like）を使うルールを再確認しましょう。
  • 日本の固有名詞（Yatsuhashi など）は、どんな食べ物か（a traditional sweet など）一言添えると親切です。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
