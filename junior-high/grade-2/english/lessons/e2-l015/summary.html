第15時限「理由を表す接続詞becauseのしくみと読解」

この時間の目標

理由を表す接続詞 because（なぜなら～だから）の用法を理解し、料理や食文化についての英文から事実とその理由を読み取れるようになることが目標です。

大事なポイント

  • 接続詞 because は「～なので、なぜなら～だから」と理由を表します（語順：結果＋because＋理由）。
  • 例：I like ramen because it is delicious.（おいしいので、わたしはラーメンが好きです）。
  • Why ～?（なぜ～ですか）に対する答えとしても Because ＋主語＋動詞. で使えます。

例題

次の2つの文を because を使って1つの文に結びましょう：I like this dish. It is very healthy.

考え方：結果（I like this dish）の後ろに because と理由（it is very healthy）をつなげます。

答え：I like this dish because it is very healthy.

つまずきやすいところ

  • because の後ろには必ず「主語＋動詞」の文を続けます（名詞だけ置きたいときは because of ～ を使います）。
  • 日本語の「～なので、…だ」と語順が逆（結果→because→理由）になることが多い点に注意しましょう。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
