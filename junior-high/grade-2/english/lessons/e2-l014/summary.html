第14時限「条件を表す接続詞ifの文」

この時間の目標

条件を表す接続詞 if（もし～ならば）を使って、ある条件のもとで起こることや自分がすることを伝え合えるようになることが目標です。

大事なポイント

  • 接続詞 if は「もし～ならば」という条件を表し、when と同じく文頭（コンマあり）でも文の途中（コンマなし）でも使えます。
  • 例：If it is sunny tomorrow, we will go on a picnic.（もしあした晴れなら、ピクニックに行きます）。
  • 最重要ルール：未来の条件であっても、if の節の中では will を使わず「現在形」にします。

例題

「もしあした雨が降ったら、わたしは家にいます。」を If を文頭にして英語で表しましょう。

考え方：if の中では未来でも現在形（三単現のs）を使うので If it rains tomorrow, とし、後ろの主節に will を使って I will stay home. とします。

答え：If it rains tomorrow, I will stay home.

つまずきやすいところ

  • If it will rain tomorrow, ... と if の中に will を入れてしまうのが定番のミスです。必ず現在形（rains）にします。
  • 主語が it（天気）なので rains に三単現のsを付け忘れないようにしましょう。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
