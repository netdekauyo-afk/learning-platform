第89時限「There is / are ～ の肯定文・疑問文のしくみ」

この時間の目標

「～がある／いる」と存在を表す There is / are ～ の肯定文・否定文・疑問文の形と意味を理解することが目標です。

大事なポイント

  • 「（ある場所に）～がある・いる」というときは、There is（後ろが単数名詞）／ There are（後ろが複数名詞）を使います。
  • 例：There is a park near my house.（家の近くに公園があります）／ There are many books on the desk.（机の上にたくさんの本があります）。
  • 否定文は There isn't / aren't ～、疑問文は Is there ～? / Are there ～? とし、Yes, there is / are. / No, there isn't / aren't. で答えます。

例題

次の(　)に is または are を入れましょう。(1) There (　) a cat under the chair.　(2) There (　) two temples in this town.

考え方：(1) 後ろが単数 a cat なので is。(2) 後ろが複数 two temples なので are を入れます。

答え：(1) is　(2) are

つまずきやすいところ

  • There is / are の文の There は「そこに」とは訳さず、後ろに来る名詞が単数か複数かで is / are を決めます。
  • 過去の「～があった・いた」は There was / were ～ となります。
