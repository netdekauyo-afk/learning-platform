第72時限「世界や地域の課題に対する自分の思いの発表」

この時間の目標

世界や地域の課題に対して自分がしたいこと（want to）やする必要があること（need to）を整理し、英語で自分の思いを発表できるようになることが目標です。

大事なポイント

  • 発表の構成例：「①テーマの紹介→②今起きている問題→③わたしたちがすべきこと（We need to ～.）→④わたしがしたいこと（I want to / try to ～.）」。
  • 自分の身近な行動（エコバッグを使う、ゴミを分別する、電気を消すなど）に結び付けて伝えます。

例題

「わたしたちは食べ物を大切にする必要があります。わたしは食べ残しをしないように努めています。」を英語で発表する文にしましょう。

考え方：We need to value food. や I try not to waste food.（または I try to eat all my food.）のように習った表現でシンプルにまとめます。

答え：We need to save food. I try to eat all my food.

つまずきやすいところ

  • 1文を長くしすぎず、need to と want to / try to を使って2〜3文で簡潔に言い切る方が聞き手に伝わります。
  • 伝えたいキーワードをゆっくり強調して発表しましょう。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
