第36時限「名詞の単数・複数と冠詞の復習演習」

この時間の目標

名詞の単数形・複数形の作り方と、冠詞（a / an / the）の基本的な使い分けを復習して定着させることが目標です。

大事なポイント

  • 数えられる名詞が1つのときは、前に a または an を付けます（後ろの語が母音の音で始まるときは an：an apple, an hour）。
  • 話し手と聞き手のあいだで「どのものか特定できるとき」や「楽器名・世界に1つのもの（the sun）」には the を付けます。
  • 2つ以上のときは複数形（-s / -es / -ies）にし、不規則な複数形（child→children、man→men、fish→fish）も押さえます。

例題

次の(　)に a または an を入れましょう：(1) (　) orange　(2) (　) umbrella　(3) (　) useful book

考え方：(1) orange は母音の音「オ」なので an。(2) umbrella は「ア」なので an。(3) useful はつづりは u ですが音が「ユ（子音）」なので a になります。

答え：(1) an　(2) an　(3) a

つまずきやすいところ

  • a と an の区別は「つづり」ではなく「発音（最初の音が母音かどうか）」で決まります。
  • water や music のように数えられない名詞には、a / an も複数形の s も付けません。
