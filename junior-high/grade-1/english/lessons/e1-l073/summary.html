第73時限「レストランでの注文表現（What would you like? / I'd like ～）」

この時間の目標

レストランで店員と客が使う丁寧な注文・応答表現（What would you like? / I'd like ～.）を理解し、やり取りできるようになることが目標です。

大事なポイント

  • 店員が注文を聞くときは What would you like?（何になさいますか）や Would you like something to drink?（お飲み物はいかがですか）を使います。
  • 客が注文するときは I'd like ～, please.（～をお願いします）を使います。I'd like は I would like の短縮形で、I want より丁寧な表現です。
  • 店内で食べるか持ち帰りかは For here or to go? と聞かれ、For here, please. / To go, please. と答えます。

例題

レストランで「ハンバーガーとオレンジジュースをお願いします。」と丁寧に注文する英語表現を書きましょう。

考え方：I'd like ～, please. を使い、a hamburger and an orange juice を続けます。

答え：I'd like a hamburger and an orange juice, please.

つまずきやすいところ

  • I'd like は I want の丁寧版ですが、I'd like to eat ～ のように不定詞を続けることもできます。
  • 注文の最後に please を添えると自然で丁寧な響きになります。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
