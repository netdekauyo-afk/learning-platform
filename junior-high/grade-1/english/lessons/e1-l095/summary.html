第95時限「思い出の出来事（My Favorite Memory）の原稿作成」

この時間の目標

中1で学んだすべての文法事項（現在形・過去形・進行形・can・want to・There is など）を活用し、思い出に残った出来事（My Favorite Memory）のスピーチ原稿を作成することが目標です。

大事なポイント

  • スピーチ原稿の構成例：①導入（My favorite memory this year is ～.）、②いつ・どこで・だれと（In October, we had ～.）、③具体的な出来事（We practiced hard. / Everyone was smiling.）、④感想と締め（It was great! Thank you.）。
  • 時制（過去のことには過去形、今の気持ちには現在形）を正しく使い分けて下書きを推敲します。

例題

「今年のわたしのいちばんの思い出は合唱祭です。わたしたちは毎日一生懸命練習しました。わたしたちは1位をとりました！」を英語のスピーチ文にしましょう。

考え方：My favorite memory this year is the chorus contest. に続けて、practiced hard と won first prize（または got first place）を過去形でつなげます。

答え：My favorite memory this year is the chorus contest. We practiced hard every day. We won first prize!

つまずきやすいところ

  • 過去の思い出なのに動詞を現在形のまま書いてしまうミスが多いので、すべての動詞の時制を見直しましょう。
  • 最後に Thank you for listening.（聞いてくれてありがとう）を添えるとスピーチらしく締まります。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
