第16時限「This / Thatの疑問文（Is this ～?）とクイズ表現」

この時間の目標

This / That の疑問文（Is this / that ～?）と答え方（Yes, it is. / No, it isn't.）を使って、身近なものについてクイズ形式でやり取りできるようになることが目標です。

大事なポイント

  • This / That is ～ の疑問文は、is を前に出して Is this ～? / Is that ～? とします。
  • 答えるときは this や that をそのままくり返さず、代名詞 it に置き換えて Yes, it is. / No, it isn't. と答えます。
  • 否定文は This is not ～ / That is not（That isn't） ～ となります。

例題

「これはあなたのノートですか。― はい、そうです。」を英語で表しましょう。

考え方：Is this your notebook? と聞き、答えは this を it に変えて Yes, it is. とします。

答え：Is this your notebook? — Yes, it is.

つまずきやすいところ

  • Yes, this is. や No, that isn't. としてしまうのが最も多いミスです。必ず it で受けましょう。
  • 名詞が1つの数えられるもの（notebookなど）のときは、a や your などを前に付けます。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
