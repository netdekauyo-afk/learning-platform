第78時限「三角形と比の定理の証明と線分の長さ」

この時間の目標

「三角形と比の定理」を相似を使って証明し、三角形の1辺に平行な直線によって分けられる線分の長さを求められるようになることが目標です。

大事なポイント

  • 三角形と比の定理：△ABCの辺AB、AC上（または延長上）に点D、Eがあり、DE // BC ならば、① AD：AB＝AE：AC＝DE：BC、② AD：DB＝AE：EC が成り立ちます。
  • ①は △ADE∽△ABC から直接導け、②は点Eを通りABに平行な補助線をひいて △ADE∽△EFC と平行四辺形DBFEから証明できます。
  • 2本の平行線（DEとBC）の長さを求めるときは、必ず「上：全体（AD：AB＝DE：BC）」を使い、「上：下（AD：DB）」とは混ぜないようにします。

例題

△ABCで DE // BC とします。AD＝4cm、DB＝2cm、BC＝9cm のとき、DEの長さx cmを求めましょう。

考え方：DEとBCは平行な2辺なので「上：全体」の比を使います。AB＝4＋2＝6cm なので、AD：AB＝DE：BC より 4：6＝x：9。2：3＝x：9 なので 3x＝18、x＝6 です。

答え：6cm

つまずきやすいところ

  • DE：BC を求めるときに誤って 4：2＝x：9 としてしまうミスが最多です。平行線どうしの比は必ず「AD：AB（上：全体）」です。
  • 砂時計型（点D、Eが延長上にある場合）でも、錯角で △ADE∽△ABC となり同じ比が成り立ちます。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
