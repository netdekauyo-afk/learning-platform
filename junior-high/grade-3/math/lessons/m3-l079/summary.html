第79時限「三角形と比の定理の逆と平行の判断」

この時間の目標

「三角形と比の定理の逆」を証明し、辺を分ける線分の比を調べることで2つの線分が平行かどうかを判断できるようになることが目標です。

大事なポイント

  • 三角形と比の定理の逆：△ABCの辺AB、AC上に点D、Eがあるとき、① AD：AB＝AE：AC ならば DE // BC、② AD：DB＝AE：EC ならば DE // BC。
  • 証明は、①なら「2組の辺の比とその間の角（∠A共通）」から △ADE∽△ABC を導き、同位角 ∠ADE＝∠ABC が等しいことから DE // BC と結論づけます。
  • 注意：「AD：AB＝DE：BC」だけでは DE // BC とは限りません（2辺と間の角にならないため）。

例題

△ABCの辺AB、AC上に点D、Eがあり、AD＝6cm、DB＝4cm、AE＝9cm、EC＝6cm のとき、DE // BC といえますか。

考え方：AD：DB＝6：4＝3：2、AE：EC＝9：6＝3：2 となり、AD：DB＝AE：EC が成り立つので、三角形と比の定理の逆より DE // BC といえます。

答え：DE // BC といえる（AD：DB＝AE：EC＝3：2 のため）

つまずきやすいところ

  • 比を比べるときは「AD：DB と AE：EC」または「AD：AB と AE：AC」のように、左右で同じ区切り方をそろえて比べましょう。
  • 「AD：AB＝DE：BC」は平行の判断には使えないので注意しましょう。
