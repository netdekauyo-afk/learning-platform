第56時限「関係代名詞that / which（目的格）のしくみ」

この時間の目標

目的格の関係代名詞 that / which の形・意味・省略のルールを理解し、ものや事柄をさらに豊かに説明できるようにします。

大事なポイント

  • 先行詞が「もの・動物」で、後ろの節の中で目的語の働きをするとき、関係代名詞 which または that を置き、「（主語）が（動詞）する（もの）」を表す。
  • 形は「もの＋(which / that)＋主語＋動詞」となり、目的格の関係代名詞は省略できる（省略した形が第52時限の接触節）。
  • 主格（直後に動詞）と目的格（直後に主語＋動詞）の見分け方を確実に押さえる。

例題

「これはガンディーが書いた本です」を目的格の関係代名詞 which（または that）を使って英語で表しましょう。

答え：This is a book which Gandhi wrote.（which を that に変えたり、省略して This is a book Gandhi wrote. としても正解です。）

つまずきやすいところ

  • 目的格の関係代名詞の後ろに、元の目的語（it / them）を重複して書かないこと。
  • 主格は省略不可、目的格は省略可能という違いを正確に区別すること。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
