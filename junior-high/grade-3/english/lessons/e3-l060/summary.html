第60時限「英語雑誌の記事への意見文（First, … / Second, …）」

この時間の目標

英語雑誌の記事などの社会的な話題に対して、I (do not) think … や First, … / Second, … を用いて2つの理由・根拠を挙げた意見文を書けるようにします。

大事なポイント

  • 意見文の基本構成：「①自分の立場（I think ... / I don't think ...）→ ②理由の予告（I have two reasons.）→ ③理由1（First, ...）→ ④理由2（Second, ...）→ ⑤結び（For these reasons, ...）」。
  • First, ... / Second, ... を使うことで、読み手にとって論理の流れが一目でわかりやすくなる。
  • それぞれの理由に短い具体例や根拠を1文添えると、説得力のある意見文になる。

例題

「私は学生がボランティア活動に参加すべきだと思います。理由は2つあります。」を英語で書いてみましょう。

答え：I think students should join volunteer activities. I have two reasons.

つまずきやすいところ

  • 反対意見を書くときは I think ... not ... より、I don't think ... の形を使うのが英語として自然。
  • First, と Second, の後ろにはカンマ（,）を忘れずにつけること。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
