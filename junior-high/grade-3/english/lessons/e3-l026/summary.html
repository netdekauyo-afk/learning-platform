第26時限「絶滅危惧種（ラッコ）の現状理解と自分の考えの表現」

この時間の目標

ラッコの生態や減少の背景について書かれた英語の記事から概要を捉え、動物保護に対する自分の考えを英語で書けるようにします。

大事なポイント

  • 記事の「何が起きているか（現状）」「なぜ起きているか（原因）」「どう守れるか（対策）」の3点を整理して読む。
  • 動物保護についての意見を書くときは、It is important for us to ... や We should ... を使うと明確に伝えられる。
  • 「～を助ける・守る」には save / protect / help などの動詞を目的に応じて使い分ける。

例題

「私たちはラッコが安全に暮らせるよう助けるべきです」を help を使って英語で表しましょう。

答え：We should help sea otters live safely.

つまずきやすいところ

  • 記事の事実（過去・現在）と自分の提案（should / want to / It is important to）の時制・表現を区別して書くこと。
  • 動物全般を話題にするときは複数形（sea otters / animals）で表すのが自然。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
