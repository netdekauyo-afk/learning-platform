第68時限「仮定法（If＋主語＋動詞の過去形）のしくみ」

この時間の目標

一般動詞の過去形を使う仮定法（If＋主語＋動詞の過去形, 主語＋would / could＋動詞の原形）の形・意味・使い方を理解できるようにします。

大事なポイント

  • If 節に一般動詞を使う場合も過去形にし、「もし（今）～すれば／～を持っていれば、…するのに」という現在の事実に反する仮定を表す。
  • 例：If I had more time, I would visit more countries.（もっと時間があれば、もっといろいろな国を訪れるのに）。
  • 普通の条件文（If it rains tomorrow, I will stay home.：現在形＋will）と、仮定法（過去形＋would / could）の違いをはっきり区別する。

例題

「もし私がタイムマシンを持っていたら、未来へ行くでしょう」を仮定法の英文にしましょう。

答え：If I had a time machine, I would go to the future.

つまずきやすいところ

  • If I have ..., I will ...（現実的な条件）と If I had ..., I would ...（非現実的な仮定）を混同しないこと。
  • 過去形を使っても「もし昨日～だったら」ではなく「もし今～だったら」という意味になることを押さえる。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
