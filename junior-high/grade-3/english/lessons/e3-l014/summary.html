第14時限「現在完了形（継続用法：for / since / How long ～?）」

この時間の目標

現在完了形の継続用法（for / since / How long ～?）のしくみを理解し、過去から現在まで続いている期間や状態をたずね合えるようにします。

大事なポイント

  • 継続用法は「（ずっと）～している」を表し、過去のある時点から現在まで状態が続いていることを伝える。
  • 期間の「長さ」を表すときは for＋期間（for three years / for a long time）、始まった「起点」を表すときは since＋時点（since 2022 / since last May）を使う。
  • 続いている期間をたずねる疑問文は How long have / has＋主語＋過去分詞 ～? を使う。

例題

次の（　）に for か since の適切な方を入れましょう。① I have lived in Kyoto (　) five years.　② She has known him (　) last spring.

答え：① for（5年間という期間の長さ）　② since（去年の春という始まりの時点）

つまずきやすいところ

  • for と since の使い分けを混同しないこと（期間＝for、起点＝since）。
  • How long ～? で聞かれたら、For ～. や Since ～. で具体的に期間・起点を答えること。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
