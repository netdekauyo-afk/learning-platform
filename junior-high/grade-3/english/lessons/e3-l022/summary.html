第22時限「現在完了形・現在完了進行形のまとめと復習演習」

この時間の目標

現在完了形の3用法（経験・完了・継続）と現在完了進行形の形・意味・使い分けを総復習し、正確に英文を作れるようにします。

大事なポイント

  • 経験（～したことがある：ever / never / once / before）、完了（～したところだ・すでに～した：just / already / yet）、継続（ずっと～している：for / since / How long）の3用法を整理する。
  • 現在完了進行形（have / has been ～ing）は「動作がずっと続いていること」を表す。
  • 過去形は「過去の1点（yesterday / two days ago / in 2020 など）」、現在完了形は「過去と現在のつながり」を表すという違いを押さえる。

例題

次の日本文を英語にしましょう。① 彼はちょうど昼食を食べ終えたところです。　② 朝からずっと雨が降り続けています。

答え：① He has just finished lunch.　② It has been raining since this morning.

つまずきやすいところ

  • yesterday や ago がある文を現在完了形にしないこと（過去形を使う）。
  • have / has の使い分けと、不規則動詞の過去分詞（written、spoken、taken など）を総点検しておくこと。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
