第54時限「関係代名詞that / which（主格）のしくみ」

この時間の目標

主格の関係代名詞 that / which の形と意味を理解し、「～するもの・こと」のように物や事柄を詳しく説明できるようにします。

大事なポイント

  • 先行詞が「もの・動物」で、後ろの節の中で主語の働きをするとき、関係代名詞 which または that を使う。
  • 「もの＋which / that＋動詞 ～」の形で、「～する（もの）」という意味になる。
  • who の場合と同じく、which / that の後ろの動詞は先行詞の単数・複数に合わせる。

例題

次の2つの文を関係代名詞 which（または that）を使って1文にしましょう。This is a robot. ＋ It can speak three languages.

答え：This is a robot which can speak three languages.（This is a robot that can speak three languages. も正解です。）

つまずきやすいところ

  • It を which / that に置き換えるので、which it can ... のように it を残さないこと。
  • 主格の関係代名詞（直後に動詞が来るもの）は省略できないことを覚えておく。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
