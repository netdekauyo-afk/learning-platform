第13時限「現在完了形（完了用法：already / yet / just）」

この時間の目標

現在完了形の完了用法（already / yet / just）の意味と使い方を理解し、すでに終えたことやまだ終えていないことを伝え合えるようにします。

大事なポイント

  • 完了用法は「（ちょうど・すでに）～したところだ・～してしまった」を表し、just（ちょうど）、already（すでに）、yet（もう／まだ）とよく一緒に使う。
  • 肯定文では just / already を have / has と過去分詞のあいだに置く（I have already finished my homework.）。
  • 疑問文では文末に yet を置き「もう～しましたか」、否定文では文末に yet を置き「まだ～していません」を表す。

例題

次の英文を「私はまだその本を読んでいません」という意味の否定文に書き換えましょう。I have already read the book.

答え：I haven't read the book yet.（否定文では already を使わず、文末に yet を置きます。）

つまずきやすいところ

  • 否定文や疑問文に already を使わず、原則として文末に yet を使うこと。
  • just / already の語順は「have ＋ just / already ＋ 過去分詞」にすること。
