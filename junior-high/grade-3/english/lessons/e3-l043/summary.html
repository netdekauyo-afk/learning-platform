第43時限「SVOO（what節：tell / show＋人＋what ～）と防災の備え」

この時間の目標

SVOO（what節：tell / show＋人＋what ～）の形と意味を理解し、災害時にどのような備えをすべきか英語で伝え合えるようにします。

大事なポイント

  • tell / show / teach＋人＋what＋主語＋動詞 で「人に～が何であるかを伝える・示す・教える」という意味を表す。
  • 間接疑問文と同じく、what（または where / how / when）の後ろは「主語＋動詞」の語順になる。
  • what we should do（私たちが何をすべきか）や what we need（私たちに必要なもの）は防災の話題でよく使われる。

例題

「この地図は私たちに、災害時にどこへ行くべきかを教えてくれます」を英語で表しましょう。（災害時に＝in a disaster）

答え：This map tells us where we should go in a disaster.（where to go と言い換えることもできます。）

つまずきやすいところ

  • what / where の後ろは「主語＋動詞」の語順にし、where should we go のように倒置しないこと。
  • tell＋人＋疑問詞節 の「人」を落とさないようにすること。

この要約の内容が分かれば、この時間の確認問題（基礎）に取り組めます。
